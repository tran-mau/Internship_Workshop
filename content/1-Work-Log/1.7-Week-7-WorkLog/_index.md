### Week 7 Objectives:

- Gain an in-depth understanding of monitoring and auditing services: AWS CloudWatch and CloudTrail.

- Practice monitoring the operating status of EC2 instances and Lambda functions using CloudWatch.

- Learn the concepts of Logs, Metrics, and Alarms in AWS.

- Set up automatic alarms when resources become overloaded.

### Results Achieved in Week 7:

- Clearly understand the difference between CloudWatch (performance monitoring) and CloudTrail (security logging/API activity history).

- Create a Dashboard to visually monitor resources.
