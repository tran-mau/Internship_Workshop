### Overview

In the Python Security Engine, **Security Checks** are responsible for verifying the security status of the Managed Nodes.

The checking modules are organized under:

~~~text
python/checks/

├── ssh_checks.py
└── firewall_checks.py
~~~

The two modules focus on the following security areas:

~~~text
Security Checks

│
├── ssh_checks.py
│   └── SSH
│
└── firewall_checks.py
    └── Firewall
~~~

![ASAU](/images/01/image_235.png)

### 1. Role of Security Checks

Security Checks perform specific security checks before the results are processed by the Security Engine.

The general workflow is:

~~~text
Managed Node

     ↓

Security Checks

     |
     +── SSH Checks
     |
     └── Firewall Checks

             ↓

          Finding
~~~

The check results provide the basis for identifying security issues that need to be analyzed or remediated.

### 2. `ssh_checks.py`

File:

~~~text
python/checks/ssh_checks.py
~~~

is responsible for checks related to SSH configuration and status.

Within the project architecture, this module verifies the SSH security requirements defined by the system.

![ASAU](/images/01/image_236.png)

![ASAU](/images/01/image_237.png)

#### How It Works

The processing flow is:

~~~text
SSH Configuration

       ↓

ssh_checks.py

       ↓

Check

       ↓

Finding
~~~

The module receives the required information, evaluates the defined conditions, and generates the corresponding result.

### 3. `firewall_checks.py`

File:

~~~text
python/checks/firewall_checks.py
~~~

is responsible for checks related to Firewall configuration and status.

The module performs the required checks to determine the Firewall state on the Managed Nodes.

![ASAU](/images/01/image_238.png)

#### How It Works

The processing flow is:

~~~text
Firewall Configuration

       ↓

firewall_checks.py

       ↓

Check

       ↓

Finding
~~~

The Firewall check results are passed to the Security Engine for further processing.

> **Note:** Specific Firewall rules and security criteria should be documented based on the FINAL version of `firewall_checks.py`.

### 4. Security Finding

The results generated by Security Checks are represented as **Finding** objects.

The relationship can be illustrated as:

~~~text
SSH Check ───────┐
                 |
                 ↓
              Finding
                 ↑
                 |
Firewall Check ──┘
~~~

A Finding contains the information required by subsequent components to analyze and process a security issue.

The Finding structure is defined in:

~~~text
python/models/finding.py
~~~

This component will be discussed in detail in the **Finding and State** section.

### 5. Relationship with the Security Engine

Security Checks do not perform the entire security workflow independently. They are components of the Python Security Engine.

~~~text
                Security Engine

                       |

             +---------+---------+
             |                   |
             ↓                   ↓

      ssh_checks.py       firewall_checks.py

             |                   |

             +---------+---------+

                       ↓

                    Finding

                       ↓

                  Next Stage
~~~

The Security Engine coordinates the overall process, while the modules under `checks/` perform individual security checks.

### 6. Overall Workflow

The overall workflow is:

~~~text
                  Managed Nodes

                       ↓

                Security Checks

                       |

             +---------+---------+
             |                   |
             ↓                   ↓

        SSH Checks        Firewall Checks

             |                   |

             +---------+---------+

                       ↓

                    Finding

                       ↓

                Security Engine
~~~

This separation allows each security area to have its own module instead of placing all checking logic into a single file.

### 7. Result

After implementing Security Checks, the Python Security Engine contains two main checking modules:

~~~text
python/checks/

│
├── ssh_checks.py
│   └── SSH Security Checks
│
└── firewall_checks.py
    └── Firewall Security Checks
~~~

These modules provide the foundation for detecting security issues. Their results are passed to subsequent components for **Finding generation, analysis, and processing**.
