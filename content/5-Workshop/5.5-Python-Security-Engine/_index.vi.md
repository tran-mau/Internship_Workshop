### Tổng quan

- Python Security Engine là thành phần xử lý logic bảo mật của project. Trong khi Ansible tập trung vào automation và configuration management, Python đảm nhiệm việc thực hiện các Security Checks, xử lý Finding, quản lý trạng thái, tạo báo cáo và hỗ trợ quá trình Remediation.  
- Python Security Engine kết hợp với Ansible để tạo thành một quy trình tự động hóa bảo mật. Python đảm nhiệm phần xử lý và phân tích logic, trong khi Ansible đảm nhiệm việc thực thi các thay đổi trên Managed Nodes.
