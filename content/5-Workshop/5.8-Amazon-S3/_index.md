+ In this chapter, we will deploy **Amazon S3** to store and manage data on AWS. S3 provides highly durable object storage that can be used to store files, application data, backups, and resources required by the system.

+ **Amazon S3** is used as a data storage service and combined with **IAM Role** to control access from EC2. Using an IAM Role allows EC2 to interact with S3 without storing the Access Key and Secret Access Key directly on the server.

+ Through S3, administrators can create **Buckets**, upload and manage objects, and check access permissions between EC2 and S3.
